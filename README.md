# MeetWave

MeetWave is a real-time video conferencing platform designed to make online meetings simple and accessible.

The project allows users to create and join virtual meetings with real-time video and audio communication, screen sharing, in-meeting chat, and basic meeting controls.


### Core Features

* User authentication
* Create and join meetings
* Real-time video and audio
* Microphone and camera controls
* Screen sharing
* In-meeting chat
* Participant management
* Meeting history
* Responsive interface

### Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* WebRTC / LiveKit
* Socket.IO
* JavaScript
